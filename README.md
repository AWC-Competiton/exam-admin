# Admin Site
1. Use the SAME Supabase project as the student site.
2. Put the same Supabase URL and public/publishable key in config.js.
3. In Supabase Authentication > Users, create an admin email/password.
4. Upload this folder to a GitHub repository, e.g. exam-admin.
5. GitHub Settings > Pages > Deploy from branch > main > /(root).
6. Admin can search, refresh, export CSV, and export Excel (.xlsx).
